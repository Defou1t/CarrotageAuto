NeuraLOG Automation — Архитектура проекта

Автоматизация оцифровки каротажных кривых (well log vectorization) · NeuraLOG v2015 · Python + Win32

❓ Что делает трейсер? Скроллирует или оцифровывает?

✓ ОЦИФРОВЫВАЕТ. Трейсер — это алгоритм автоматического следования по кривой на сканированном изображении. Он читает пиксели, определяет положение линии кривой и записывает координаты (глубина, значение).

✗ Не скроллирование

  • Не листает страницы
  • Не двигает ползунок просмотра
  • Не делает скриншоты

✓ Векторизация (оцифровка)

  • Читает пиксели изображения
  • Следует за линией кривой
  • Mapped Point = 3087.5M, -636.8 Ohmm
  • Результат → LAS-файл с числовыми данными
image.tif/jpg → NeuraLOG Tracer (BTN_FORWARD) → Mapped Points (3080m…3520m) → export.las
Пиксели изображения  →  Алгоритм NeuraLOG  →  Глубина + Значение (Ohmm)  →  LAS 2.0

Известные проблемы и статус исправлений

ПроблемаПричинаИсправление
Открывается старый проект (depth=4357 вместо 3080) MDI-приложение: Ctrl+O открывает файл, но MDI-фокус остаётся на предыдущем switch_to_project() → WM_MDIACTIVATE перед трейсингом
Диалог экспорта не открывается автоматически PostMessage не обрабатывается когда окно свёрнуто/не в фокусе SendMessage (синхронно) + MDI-child fallback + hotkey fallback
Файл экспорта создаётся в /las/ проекта, не в /output/ WM_SETTEXT не менял путь в Edit (Edit мог быть неверным) id=3369 (из probe), затем _find_recent_las() + shutil.copy2()
Таймаут трейсинга 900с (15 мин) — мало для 440м Жёстко задан CFG["trace_timeout"] max(1800, remaining/0.20) — ~37 мин для 440м
UIA backend не работает 32-bit приложение + 64-bit Python Используем только win32 backend. UIA убран полностью.

Структура данных

F:\nds\projects\Well_A\wlg\Well_A_BK_3080_3520_200_D1.nlgx → Трейсинг 3080→3520м → F:\nds\output\Well_A_BK_3080_3520_200_D1.las
Бинарный C++ формат, содержит растровое изображение + цифровые кривые                                            LAS 2.0: ASCII, ~Depth,BK,MBK столбцы, шаг 0.1м
Парсинг имён файлов: Semeguniv_20_BK+MBK_3080_3520_200_D1 → depth_from=3080, depth_to=3520, dpi=200. Паттерн: _(\d{3,5})_(\d{3,5})_(\d{2,4}) — три числа подряд = from, to, dpi.
