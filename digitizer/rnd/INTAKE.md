## Если кончилось место

Загрузчик останавливается сам ниже 30 ГБ свободного и пишет об этом в `progress_*.txt`. Дальше:
1. посмотреть, что занято: `du -sh E:/Carrotagki_auto/*`;
2. распакованное (`intake\unpacked`) можно удалить — оно воссоздаётся из архивов;
3. поднять порог/сменить диск: `--min-free 15` или `--dst <другой диск>`;
4. повторить команду выше — докачается только недостающее.

## Если оборвалась сессия Telegram

`sqlite3.OperationalError: database is locked` = запущены две копии загрузчика. Снять лишние:

```bash
powershell -NoProfile -Command "Get-CimInstance Win32_Process -Filter \"Name='python.exe'\" | Where-Object { $_.CommandLine -like '*_tg_fetch*' } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }"
```

Если сессия перестала быть авторизованной — вход делает ВЛАДЕЛЕЦ: `python _tg_login.py`
(агент к учётным данным не прикасается). Файл сессии: `E:\Carrotagki_auto\intake\user.session`.

## Что делать с данными, когда скачаются

1. **Разложить и получить аудит** — шаг 3 скрипта; печатает полные комплекты, «nlgx без скана»
   (список поиска), «скан без разметки», нераспознанные имена, конфликты версий.
2. **Сорта эталона.** Папка `for Bodya_Cherk` (когда владелец её выложит) — сорт **A**, проверенный
   экспертом. Выгрузка из телеграма — сорт **B**: возможны ошибки оцифровки, **имён методов**, шкал
   axis/depth. При совпадении листа берётся A. Суффикс «(1)» = несколько версий разного качества,
   молча не выбирать. Подробности — память `carrotage-truth-tiers`.
3. **Проверить имена методов** таблицами `Додаток` (xlsx из чата Богдана):
   `python _xlsx_check.py --xlsx <файл> --wlg <каталог>`. На проверенной скважине даёт 112/114 и
   ловит настоящие опечатки (`OZG` вместо `OGZ`).
4. **Измерить шум эталона:** листы, попавшие И в A, И в B, дают расхождение самого эталона — это
   доверительный интервал нашей метрики, которого у проекта никогда не было.
5. **Только потом** — перенос в боевой `F:\nds\projects\Archive`, отдельным осознанным шагом.
