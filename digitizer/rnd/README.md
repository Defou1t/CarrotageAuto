# digitizer/rnd — спасённый R&D-скретч (ROADMAP §7)

Эти скрипты — **исходный R&D из `F:\nds\output\`**, перенесённый в git, чтобы не потерять
(ROADMAP_v2 §7: «Лучшие результаты — в скретче вне git → перенести в `digitizer/` и закоммитить»).
Это **экспериментальный скретч**, не продакшн-модули: абсолютные пути (`F:\nds\Auto\digitizer`,
`F:\nds\output`, `D:\ComfyUI`), запуск был штучный. Унификация путей = отдельный пункт Stage 0.
Каноничный конвейер живёт в [`auto/`](../../auto); здесь — наработки-первоисточники его рецептов.

⭐ = durable «best result», прямо названный в ROADMAP §2 (ОСТАВИТЬ) / §7.
