# digitizer/rnd — R&D-стенды ветки распознавания

Здесь живут **замерные стенды** (`_*.py`), а не продакшн. Канонический конвейер — [`auto/`](../../auto).

| зачем пришёл | куда идти |
|---|---|
| ★ **состояние ветки, что делать дальше** | [HANDOFF.md](HANDOFF.md) — верхний блок |
| какой стенд что меряет, чьи числа отозваны | ★ [STANDS.md](STANDS.md) — указатель ВСЕХ `*.py` каталога |
| откуда взялось число | [../../ROADMAP_RECOGNITION.md](../../ROADMAP_RECOGNITION.md), разделы `§6.x` |
| что можно удалять из `output/` | [DATA_RETENTION.md](DATA_RETENTION.md) (исполняемая часть — `_data_retention.py`) |

**Указатель проверяется машиной:** `python _stand_audit.py` — падает, если появился стенд без
строки в `STANDS.md` или строка без файла. Запускать после добавления любого `_*.py`.

**Интерпретатор.** Всё, что трогает torch, запускать embedded-питоном ComfyUI
(`D:/ComfyUI/ComfyUI/ComfyUI_windows_portable/python_embeded/python.exe`) — в дефолтном python
проекта torch нет.

**Дисциплина стенда** (полностью — в шапке STANDS.md): сверка объёма выборки печатается ПЕРВОЙ;
число листов берётся из счётчика, а не пишется в текст; у режима обязан быть след, который стенд
проверяет; два счёта одного прогона снимаются ОДНИМ проходом.

⚠ Это экспериментальный скретч: абсолютные пути (`F:\nds\...`, `D:\ComfyUI`), запуск штучный.
Историческое описание каталога (срез до §6.20) — `archive/docs/rnd_README_full.md`.
